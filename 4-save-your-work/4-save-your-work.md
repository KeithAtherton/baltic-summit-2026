# How to save your work

## Your workshop solution

To save your work stored in the *Future Is Now Workshop* solution, [export the solution](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/export-solutions) and save the zip file somewhere safe, e.g. your personal OneDrive.

## Workshop examples solution

To save the workshop examples stored in the *Future Is Now Workshop - Examples* solution, [export the solution](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/export-solutions) and save the zip file somewhere safe, e.g. your personal OneDrive.

## Code Apps code

To save your Code Apps code, this is already saved to C:\code on your laptop. Consider also saving this somewhere safe, e.g. your personal OneDrive.
